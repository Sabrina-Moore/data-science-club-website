## About The Project
This is a React JS and Vite website for the El Camino College Data Science Club. It's comprised of a home page for introducing members to the club, a projects page for sharing completed projects, and an events page for upcoming and past events hosted by the club. 

<p align="right">(<a href="#readme-top">back to top</a>)</p>

## Features
- Responsive navigation bar for linking to pages
- Array of objects for mapping links and club officers into cards
- Array of objects with sorting for upcoming and past events
- Material UI components

## Running the App

### Prerequisites

- [Node.js](https://nodejs.org/) 20 or later
- npm (included with Node.js)

### Getting Started

1. Clone the repository and move into the project directory:

   ```bash
   git clone https://github.com/ecc-data-science-club/datascience-club-site.git
   cd datascience-club-site
   ```

2. Install the project dependencies:

   ```bash
   npm install
   ```

3. Start the local server:

   ```bash
   npm run dev
   ```

4. Open the local URL shown in your terminal (usually `http://localhost:5173`) in a browser. Vite will automatically refresh the page as you save changes.

### Other Commands

- `npm run build` creates an optimized production build in `dist/`.
- `npm run preview` serves the production build locally after running `npm run build`.
- `npm run lint` checks the project with ESLint.
